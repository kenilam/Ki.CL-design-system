The components, styles and icons Ki.CL is built from. Each page shows one component live: pick a preset, toggle its props, and copy the code for what you see.

## Get started

The design system is a Module Federation remote called `design`. Import `design/core` once, before anything else, then import components from `design/components` and routing from `design/router`.

```
import 'design/core';
import { Button } from 'design/components';
```

Props like `variant`, `size` and `level` set how a component looks. [Layout](../components/layout/layout) props set how things are arranged, and `kicl-*` utility classes cover the rest. A view only writes its own CSS when none of those can do the job.
