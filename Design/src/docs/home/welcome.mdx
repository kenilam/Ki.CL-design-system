These are the components, styles and icons Ki.CL is built from. Each page shows one component live. Pick a preset, toggle its props, and copy the code for what you see.

## Using it

The design system is a Module Federation remote called `design`. Import components from `design/components`, import `design/core` once before anything else, and get routing from `design/router`.

```
import { Button } from 'design/components';
```

Props like `variant`, `size` and `level` set how a component looks. `Layout` props set how things are arranged, and `kicl-*` utility classes cover the rest. Views only write their own CSS when none of those can do the job.
