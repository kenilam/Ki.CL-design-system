Patterns show how components work together to solve a common problem: telling someone what happened, asking for information, picking from options, or pausing a task to confirm it. Each one starts from what the browser already does and adds as little as it can.

The first group is about building for everyone from the start. Much of it comes from choosing the right element and writing clear content, which is easier at the start than as a fix later.
