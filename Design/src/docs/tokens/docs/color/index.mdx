## Body and surface

Four roles cover most of the page. `--kicl-body-color` is text and `--kicl-body-background-color` is the page behind it. `--kicl-surface-color` is anything raised off the page, like a card, a popover or a field, and `--kicl-surface-border-color` is its edge. A surface is a short step away from the background, lighter on both themes, so it always reads as raised.

`kicl--theme--light` and `kicl--theme--dark` set these roles. Components don't know which theme they're in. They read the roles, so the same card below takes both themes without a prop.

## Classes

The patterns are `kicl-color-{name}`, `kicl-background-color-{name}` and `kicl-fill-{name}`, where `{name}` is any colour above.

```tsx
// Text in blue, and anything inside that reads the body colour
<p className='kicl-color-blue' />

// A light grey fill behind a block
<div className='kicl-background-color-grey-light' />

// An SVG icon in the error colour
<svg className='kicl-fill-error' />

// The page's own background, on a panel that must cover what's behind it
<aside className='kicl-background-color-body' />
```

`kicl-color-{name}` sets `--kicl-body-color` as well as `color`, so an icon or a border inside picks up the colour too. `kicl-fill-{name}` is for SVG.

The body colours have their own:

- `kicl-color-body-color` and `kicl-fill-body-color` use the text colour.
- `kicl-background-color-body` uses the page colour, and `kicl-background-color-body-color` fills with the text colour.

`kicl-color-gradient-rotate-0deg`, `90deg`, `180deg` and `270deg` set `--kicl-color-gradient-rotate`, the angle of the site's gradient.
