## Classes

The patterns are `kicl-pointer-events-{keyword}`, `kicl-cursor-{keyword}`, `kicl-touch-action-{keyword}` and `kicl-user-select-{keyword}`, where `{keyword}` is the CSS value listed above.

```tsx
// Clicks go through it to whatever is underneath
<div className='kicl-pointer-events-none' />

// Shows it can be dragged
<div className='kicl-cursor-grab' />

// Scrolls the page up and down, and leaves sideways swipes to the element
<div className='kicl-touch-action-pan-y' />

// Its text can't be selected, as on a control
<span className='kicl-user-select-none' />
```
