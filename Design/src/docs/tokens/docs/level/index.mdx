`level` says what something means, and each one has a colour: `confirm`, `error`, `info` and `warning`. The same level is the same colour on Button, Badge, Card, Bubble, Heading, Text, Status, Markdown and Diagram. Status has no `confirm`.

Level and variant are separate props. A secondary error button is a tint of the error colour, and a card with a level only colours its edge.

## Variables

`warning` mixes yellow and orange on a light page and is plain yellow on a dark one. The others point at a hue.

## Classes

In a component, use the `level` prop, so the label, the fill and the edge stay in step. Outside one, the same colours apply with `kicl-color-{level}`, `kicl-background-color-{level}` and `kicl-fill-{level}`, where `{level}` is `confirm`, `error`, `info` or `warning`.

```tsx
// A card with its edge in the error colour
<Card level='error' />

// Text in the confirm colour, and anything inside that reads the body colour
<Text className='kicl-color-confirm'>Saved</Text>

// A warning fill behind a block
<div className='kicl-background-color-warning' />

// An SVG icon filled with the info colour
<svg className='kicl-fill-info' />
```
