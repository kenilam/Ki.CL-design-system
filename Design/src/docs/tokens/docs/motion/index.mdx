## Classes

The pattern is `kicl-transition-duration-{step}`.

```tsx
// Transitions over 480ms
<div className='kicl-transition-duration-fast' />

// Fades in as it scrolls into view, from below
<li className='kicl-scroll-reveal' />

// A spinning icon that stops for anyone who asks for less motion
<svg className='kicl-animation-none-reduced-motion' />
```

`{step}` is `fastest`, `faster`, `fast`, `slow`, `slower`, `slowest` or `extreme`. Leave it out for the default. The longer durations, `6s` to `5m`, are variables only.

Easing has no classes. Read it in CSS, as in `transition-timing-function: var(--kicl-ease-quad-out)`.

- `kicl-scroll-reveal` fades and slides an element in from below as it scrolls into view. `kicl-scroll-reveal-start` and `kicl-scroll-reveal-end` bring it in from the inline start or end.
- `kicl-animation-none` stops an element's own animation, such as a skeleton standing in for something that isn't loading.
- `kicl-animation-none-reduced-motion` stops an element's animation when the person asks for less motion.
- `kicl-visibility-hidden-reduced-motion` hides something that only makes sense with motion.
