## Classes

The patterns are `kicl-overflow-{keyword}`, `kicl-overflow-{x|y}-{keyword}`, `kicl-overscroll-behavior-{keyword}` and `kicl-contain-{keyword}`.

```tsx
// Scrolls top to bottom when its content is taller than it
<div className='kicl-overflow-y-auto' />

// Scrolling inside it stops at its end instead of moving the page
<div className='kicl-overflow-y-auto kicl-overscroll-behavior-contain' />

// Scrolls sideways with no scrollbar, and fades at the edges
<ul className='kicl-overflow-x-auto kicl-scrollbar-none kicl-scroll-fade' />

// Fills the rest of a fit-content parent instead of setting its width
<div className='kicl-contain-inline-size' />
```

`{keyword}` for overflow is `auto`, `clip`, `hidden`, `scroll` or `visible`. For contain it's `none`, `content`, `inline-size`, `layout`, `paint`, `size` or `strict`. `kicl-contain-inline-size` keeps an element out of its parent's width, so a fit-content parent sizes to its other children and this one fills the rest.

- `kicl-scrollbar-none` hides the scrollbar and keeps the scrolling.
- `kicl-scroll-fade` fades the content out at the edges it can scroll toward.
- `kicl-stuck-line-start` and `kicl-stuck-line-end` draw the site's gradient along a sticky element's edge while it's stuck: `start` for a footer stuck to the bottom, `end` for a header stuck to the top.
