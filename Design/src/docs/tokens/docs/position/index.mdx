Classes that set `position`. Place the element with the inset classes on [Sides](../tokens/semantics/sides).

## Variables

### position

MDN: [`position`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/position).

<Variables
  names={[
    'position-absolute',

    'position-initial',

  ]}
  property='position'
  preview={Position}
/>

## Classes

The pattern is `kicl-position-{keyword}`, where `{keyword}` is any value above.

```tsx
// The box its absolute children are placed in
<figure className='kicl-position-relative' />

// Pinned to the top-right corner of that box on a left-to-right page
<span className='kicl-position-absolute kicl-inset-block-start-0 kicl-inset-inline-end-0' />

// Sticks under the global header as the page scrolls
<nav className='kicl-position-sticky kicl-inset-block-start-header' />
```
