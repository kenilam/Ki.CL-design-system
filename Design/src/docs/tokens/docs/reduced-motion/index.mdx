When someone sets their system to reduce motion, the components below stop animating on their own and still show their end state. Two classes cover anything else that moves.

## What changes by itself

- `Animation` cuts its duration to nothing, so the end state and its events still arrive.
- Frames, sheets, the segmented control's thumb and skeleton shimmer stop animating.
- `kicl-scroll-reveal` content just shows, without sliding in.
- Same-page links jump instead of scrolling smoothly, and the global header stops sliding.

## Classes

```tsx
// A spinner that stops for anyone who asks for less motion
<svg className='is-revolving kicl-animation-none-reduced-motion' />

// A control that only makes sense with motion, hidden when motion is off
<button className='kicl-visibility-hidden-reduced-motion' />
```

- `kicl-animation-none-reduced-motion` stops an element's own animation.
- `kicl-visibility-hidden-reduced-motion` hides something that only works with motion. Pair it with `kicl-animation-none-reduced-motion` when an animation sets `visibility`.

Write anything new that moves inside `@media (prefers-reduced-motion: no-preference)`, so it's off unless the person is happy with motion.
