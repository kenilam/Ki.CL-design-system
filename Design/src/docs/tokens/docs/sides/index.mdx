Everything is written with logical properties, block and inline, start and end, never top or left. On a left-to-right page, `block-start` is the top, `block-end` the bottom, `inline-start` the left and `inline-end` the right. A right-to-left page flips without any change.

Popover placements and Sheet sides take the same four names, `block-start`, `block-end`, `inline-start` and `inline-end`.

## Classes

A class that sets one side names the axis, then the edge, then the step: `kicl-{property}-{axis}-{edge}-{step}`.

- `{axis}` is `block` or `inline`. Leave it out for both axes.
- `{edge}` is `start` or `end`. Leave it out for both edges of the axis.
- `{step}` is a gutter step, see Spacing. Leave it out for the default.

So `kicl-padding` is all four sides, `kicl-padding-block` is top and bottom, and `kicl-padding-block-start` is the top alone. Padding, margin and inset all follow this order.

```tsx
// All four sides, 1rem
<div className='kicl-padding' />

// Top and bottom, 1rem
<div className='kicl-padding-block' />

// Top only, 0.5rem
<div className='kicl-padding-block-start-narrow' />

// Left and right on a left-to-right page, 2rem
<div className='kicl-margin-inline-wide' />

// Right only on a left-to-right page, left on a right-to-left one
<div className='kicl-margin-inline-end-narrower' />
```

## Inset

Inset places a positioned element, and needs a `kicl-position-*` class to do anything. It takes the gutter steps and also `0` and `auto`, as `kicl-inset-{axis}-{edge}-{step}`.

```tsx
// Pinned to the top-right corner on a left-to-right page
<div className='kicl-position-absolute kicl-inset-block-start-0 kicl-inset-inline-end-0' />

// 0.5rem in from every edge of its positioned parent
<div className='kicl-position-absolute kicl-inset-narrow' />

// Centred top to bottom, without a transform
<div className='kicl-position-absolute kicl-inset-block-center' />
```

Some insets are named for what they line up with:

- `kicl-inset-block-start-header` sits under the global header while it shows, and at the top while it hides.
- `kicl-inset-inline-end-frame` lines up with the page's frame.
- `kicl-inset-inline-screen` stretches a positioned element to the full screen width from inside a narrower parent.
- `kicl-inset-block-center` and `kicl-inset-inline-center` centre a positioned box on one axis without a transform. Add a step, as in `kicl-inset-block-center-wide`, to keep it that far from both ends.
