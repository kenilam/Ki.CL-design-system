`--kicl-size` is 16px, and most of the scale is multiples of it, with a few smaller steps like `half` and `hair`. Radius and the named widths pick points on it, and Card `size` takes the same names.

## Columns

Widths come from a 12-column scale. Twelve columns are the page, at most 80rem, and a span of `n` is `n` columns plus the gaps between them, so a width lines up with a real 12-column grid. The `kicl-inline-size-columns-*` and `kicl-max-inline-size-columns-*` classes never go wider than their parent, so a span set with them can't cause horizontal scroll. Card and Sheet `size`, and Layout `span`, take the same numbers.

## Classes

Radius picks a size by name, as `kicl-border-radius-{name}`:

```tsx
// Corners rounded by 1rem
<div className='kicl-border-radius-md' />

// A circle, on a square box
<img className='kicl-border-radius-full kicl-aspect-ratio-square' />
```

`none` 0, `xs` 2px, `sm` half, `md` 1x, `lg` 2x, `xl` 3x, `xxl` 4x, `max` 6x and `full` 100%.

Width picks a size by name, as `kicl-inline-size-{name}`, or a column span, as `kicl-inline-size-columns-{1…12}` and `kicl-max-inline-size-columns-{1…12}`:

```tsx
// 160px wide
<div className='kicl-inline-size-md' />

// Six columns wide, or the parent's width if that's narrower
<div className='kicl-inline-size-columns-6' />

// Fills the parent, up to eight columns
<article className='kicl-max-inline-size-columns-8' />
```

`xs` 4x, `sm` 6x, `md` 10x, `lg` 14x, `xl` 16x, `xxl` 18x, `max` 20x, `full` 100% and `screen` the viewport width. There's no `kicl-min-inline-size-columns-*`.

Height takes a column span, as `kicl-min-block-size-columns-{1…12}` and `kicl-max-block-size-columns-{1…12}`, the parent, as `kicl-block-size-full`, or the screen:

```tsx
// As tall as the parent
<div className='kicl-block-size-full' />

// At least as tall as the screen
<main className='kicl-min-block-size-screen' />

// No taller than half the screen, and scrolls inside
<div className='kicl-max-block-size-screen-half kicl-overflow-y-auto' />

// As tall as an input, to line up with one
<div className='kicl-min-block-size-field' />

// At least two columns tall
<pre className='kicl-min-block-size-columns-2' />
```

`screen` follows the visible viewport as mobile browser bars come and go. `kicl-min-block-size-field` is as tall as an input. `kicl-min-inline-size-0` lets a grid or flex child shrink below its content, so text in it can truncate instead of pushing its row wider.

Aspect ratio is `kicl-aspect-ratio-{auto|square|video}`:

```tsx
// 16:9, for a video or its placeholder
<div className='kicl-aspect-ratio-video' />
```
