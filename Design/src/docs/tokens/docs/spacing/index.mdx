`gap` takes the gutter scale. It's a prop on Layout and on every component built on it, like List, ListItem, Button and Card, rather than a class.

The default step, `normal`, is `--kicl-gutter`, 1rem, and is left out of class names. Each narrow step halves the one before, and the wide steps grow from it.

Padding, margin and inset utilities use the same steps.

## Classes

The pattern is `kicl-{property}-{step}`.

```tsx
// Spacing between children, through Layout and anything built on it
<List gap='narrow' />

// padding on all four sides, the default 1rem gutter
<section className='kicl-padding' />

// padding on the top and bottom, 2rem
<section className='kicl-padding-block-wide' />

// margin before the element on its row, 0.5rem
<span className='kicl-margin-inline-start-narrow' />

// no margin at all
<p className='kicl-margin-none' />
```

`{property}` is one of:

- `padding`, `padding-block`, `padding-block-start`, `padding-block-end`, `padding-inline`, `padding-inline-start`, `padding-inline-end`
- `margin`, `margin-block`, `margin-block-start`, `margin-block-end`, `margin-inline`, `margin-inline-start`, `margin-inline-end`

`{step}` is `none`, `narrowest`, `narrower`, `narrow`, `wide`, `wider`, `widest` or `extreme`. Leave it out for the default gutter.

A few take a keyword in place of a step:

- `kicl-margin-inline-auto` centres a block in its row.
- `kicl-margin-inline-start-auto` pushes the element to the end of its row, and `kicl-margin-inline-end-auto` pushes what follows it.
- `kicl-padding-inline-frame`, `kicl-padding-block-frame`, `kicl-padding-block-start-frame` and `kicl-padding-block-end-frame` inset content the same as a Frame. `kicl-padding-inline-frame-columns-12` does the same and also keeps it within 12 columns.
- `kicl-padding-block-start-header` clears the fixed global header.

Inset uses the same steps, listed on [Sides](../tokens/semantics/sides).
