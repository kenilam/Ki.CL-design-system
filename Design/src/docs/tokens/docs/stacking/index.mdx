`--kicl-z-index-{role}` picks a layer by what it's for, not by a number higher than the last one.

## Variables

## Classes

The pattern is `kicl-z-index-{role}`.

```tsx
// Above the content around it, as a sticky toolbar
<header className='kicl-position-sticky kicl-z-index-floating' />

// Behind its siblings, as a decorative layer
<div className='kicl-position-absolute kicl-z-index-behind' />
```

`{role}` is `behind`, `base`, `raised`, `floating`, `popover`, `overlay`, `header` or `top`, lowest first.
