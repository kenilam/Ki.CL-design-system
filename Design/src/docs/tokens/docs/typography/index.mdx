## Families

`bold` is the same face as the default, and `kicl-font-family-bold` also sets `--kicl-font-weight-bold`. `special` is the rounded face for display text. `mono` is for data, like version numbers and counts, and sets tabular figures so a column of numbers doesn't shift.

<TypeScale names={['', 'bold', 'special', 'mono']} property='font-family' />

## Sizes

Sizes are in rem, from the 16px root. Nothing goes below 12px, so `smallest` is still readable, and body text stays at the 16px default. `large` and `larger` set the line height to 1.2, and `largest`, `huge` and `extreme` to 1, so the gap between lines doesn't grow with the text. `huge` and `extreme` aren't shown here: they grow with the viewport.

### heading

MDN: [`font-size`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-size), [`font-weight`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-weight) and [`color`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/color).

Every `h1` to `h6` sets these for itself, so the values below are read from an `h4`. Only the size changes by level: each level steps down a size, `h4` is the body size, and `h5` and `h6` are small, with `h6` in capitals and dimmed as a label. `--kicl-heading-status-color` is set by a heading's `level`, and `--kicl-heading-font-size-scale` lets a variant quieten any level.

## Classes

Each variable has a class with the same name, `kicl-font-size-{name}`, `kicl-font-weight-{name}` and so on:

```tsx
// 14px text
<Text className='kicl-font-size-small' />

// Weight 600
<Text className='kicl-font-weight-bold' />

// The monospace face with even-width figures, for a version or a count
<Text className='kicl-font-family-mono' />

// Lines 1.2 apart, for a tight block of large text
<Text className='kicl-line-height-narrow' />

// Short lines of a heading evened out
<Heading className='kicl-text-wrap-balance' />
```

Leave the variation out for the default, as in `kicl-font-size` or `kicl-line-height`. Type is set once on `body` and inherited, so a class on a parent reaches the text inside it.

Keyword classes set the CSS value directly: `kicl-font-style-{normal|italic|oblique}`, `kicl-text-align-{start|center|end|justify}`, `kicl-text-transform-{none|capitalize|lowercase|uppercase}` and `kicl-text-nowrap`.

```tsx
// Centred text
<Text className='kicl-text-align-center' />

// Capitals, as on a button label
<Text className='kicl-text-transform-uppercase' />

// Kept on one line
<Text className='kicl-text-nowrap' />
```

`kicl-look-like-{element}` gives something the look of another element without changing what it is, so a heading's level in the outline and its size on the page can differ. `{element}` is `h1` to `h6`, `blockquote`, `cite`, `code`, `del`, `em`, `ins`, `pre`, `q` or `strong`. The headings also take `--variant--secondary`, as in `kicl-look-like-h2--variant--secondary`. On `Text` and `Heading`, use the `lookLike` prop.
